# Track: lower bounds

Goal: a lower bound for a wider class of algorithms than the existing ones, or a conditional hardness result
for 2-list stable matching.

## What exists

[../../docs/summary.md](../../docs/summary.md), section "Lower bounds and barriers":

- B2, B3, B6, B11-B14: explicit families force quadratic work in specified proposal and unit-charge models.
  The models are stated exactly there. The subquadratic draft is outside them.
- B4 (S, A~): under NSETH, fast verification blocks specified deterministic fine-grained SAT reductions.
- B17: a finite forcing-certificate argument (P, A0 for its written lemmas and checked sizes; the extension to
  all sizes is C, A0).

A useful result names its model precisely and shows that it includes algorithms not covered before. A hard
family for a stated class of algorithms is a good negative result for the polynomial-speedup track.
