# Track: formal proofs

Goal: machine-checked proofs of results that are only checked by hand review and finite tests.

Candidates:

- Theorem 4.11 (structural projection) and Proposition A.3 (unique minimum seam) of
  [../../paper/twolist-subquadratic.pdf](../../paper/twolist-subquadratic.pdf).
- D1/D2: the rotation bound and the 2^floor(n/2) bound on stable matchings
  ([../../docs/rotations.md](../../docs/rotations.md)).

The repository has no proof-assistant setup. Put the project in your entry folder, with the tool and library
versions, the build command, and the exact theorem statements. List every remaining gap (for example, `sorry`
in Lean) if the proof is partial.
